MVP de historia clínica personal con acceso profesional bajo grant revocable.

- [`doc/ARQUITECTURA/ARQUITECTURA.md`](doc/ARQUITECTURA/ARQUITECTURA.md) — vocabulario, responsabilidades, hexagonal + DDD.

## Cómo contribuir

- Humanos y agentes AI: leer primero [`AGENTS.md`](AGENTS.md).
- Configuración objetivo del `tsconfig.json`: [`doc/CONFIG/tsconfig-target.md`](doc/CONFIG/tsconfig-target.md) cuando exista.

## Estado

Este repositorio contiene **documentación conceptual y configuración inicial**. Ningún backend está ejecutable, no hay clientes desplegados, no se cargaron datos clínicos reales y la habilitación de los mismos requiere aprobación humana explícita.

> "Lista de espera de unas 1.000 personas" no equivale a cuentas activas ni a concurrencia verificada. Ver [`doc/README.md`](doc/README.md) para el alcance real.
